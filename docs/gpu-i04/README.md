# I04 — dane i próby

Raport: ../I04_GPU_COUPLING.md. baseline/ zawiera pomiar oryginalnego I03. benchmark/ to pierwsza seria bez sceny aktywnych kontaktów. final-benchmark/ to pierwsze pięć scen przed rozdzieleniem buforów; optimized-benchmark/ to końcowe pięć scen, w tym coupled_tank z mierzoną niepustą kolejką. quality/combined/ to pełna misja eksperymentu łączonego. tests/ to przebieg z pierwotnym układem buforów; tests-final/ to końcowy CTest i dodatkowe kontrole, tests-initial-local/ to przerwany przebieg przed wyborem konfiguracji. first-check/ oraz coupling-check/ zachowują błędy rozwoju testu i pierwszego nadzoru WSL; native-coupling-check/ zawiera późniejszy poprawny audyt z natywnym czekaniem. windows/ zawiera wszystkie próby okna z kodami błędów. package-check/ dotyczy paczki Windows. Kod 77 oznacza pominięcie testu GPU, nie jego zaliczenie.
